# Египетская система счисления

Учебный сайт Златы по информатике. Практические работы 4–6.

## Возможности

- Статьи об египетской системе счисления.
- Поиск по заголовкам, тексту и тегам.
- Переключение светлой и тёмной темы.
- Адаптивное оформление для телефона и компьютера.

## Сайт

https://Khzlata2005.github.io/egyptian-numerals/

## Запуск

Откройте папку проекта через Live Server в VS Code.
Сайт использует HTML, CSS и JavaScript и не требует сборки.

## Проверка оформления

`npx prettier --check .`

Ширина строк кода — не более 40 символов.
